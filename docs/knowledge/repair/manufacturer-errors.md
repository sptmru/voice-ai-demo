# Unknown models and error codes

## Model clarification

The same error code can mean different things across manufacturers. Ask for the brand and full model before explaining a code. This corpus covers fictional Relay Wash W100/W200, Relay Dish D100 and Relay Cool C100 only. It has no verified code tables for Bosch, Samsung, LG or other actual manufacturers. Do not transfer Relay instructions to them; offer an operator or diagnosis if no applicable manual exists.
