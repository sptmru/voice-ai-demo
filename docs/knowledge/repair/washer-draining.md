# Relay Wash W100: Water will not drain

## W100 drain fault

For fictional Relay Wash W100 only, E21 concerns draining. The code alone does not prove pump failure or justify replacement. Ask when it appeared, whether water remains and whether there was unusual noise. Never force a locked door, dismantle the pump, filter or wiring, or tip a full machine on an assistant's advice. Stop use if water leaks; disconnect power only if safe. A technician diagnoses the cause.
